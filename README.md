Reason: Health statistics are often just numbers in reports and they are easy to ignore. I wanted to feel  the burden of tuberculosis leading to death of children worldwide feel real!!!..
Why? The app has no real-time hospital data. It uses one average: one child dies every 3 minutes. It asks the clock how much time has passed this year and today, then divides by 3 minutes to get “how many would have happened by now”. Every second it repeats, so the numbers and countdown move.
Steps
First I tired the idea to calculate deaths according to if every 3 minutes one child dies than how many deaths an hour, day, and year. After testing it and running it on streamlit and my computer. I moved on the script to use python to do the math and build a code which counts the estimate deaths so far this year and today, and a countdown to the next one, updating every second. 
I uploaded the files to GitHub and deployed through Streamlit Community Cloud. I solved a connection problem and a branch problem to get the live version working, and I now have a public link.
Learning:
I learned to write and debug Python, deploy an app, and handle problems like file names, folders and GitHub branches. I also learned the importance of labelling an estimate as an estimate.
I am both excited to keep building this and learning new things along the way.
